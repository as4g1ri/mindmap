# MindMonitor

MindMonitor — это React-прототип мобильного интерфейса для мониторинга психоэмоционального состояния пользователя. Проект демонстрирует пользовательский сценарий от первого запуска и регистрации до просмотра аналитики, рекомендаций, дневника, уведомлений и отчётов.

Прототип создан как интерактивная UI-демонстрация. Он показывает структуру экранов, навигацию и ключевые точки взаимодействия, но не реализует полноценную бизнес-логику, серверную часть и постоянное хранение данных.

## Назначение

Интерфейс иллюстрирует, как пользователь:

- знакомится с приложением на приветственном экране;
- проходит регистрацию или авторизацию;
- даёт согласие на обработку данных;
- предоставляет разрешения на доступ к данным устройства;
- получает сводку по текущему состоянию;
- изучает аналитику и рекомендации;
- ведёт дневник состояния;
- управляет уведомлениями и настройками;
- просматривает историю и интерфейс отчётов.

## Основные возможности

- Приветственный экран с кратким описанием назначения приложения.
- Регистрация и вход с базовыми формами.
- Экран согласия на обработку персональных данных.
- Экран разрешений на доступ к данным устройства:
  - физическая активность;
  - сон;
  - уведомления;
  - экранное время.
- Главный экран с обзором состояния и быстрым доступом к ключевым разделам.
- Аналитика с визуализацией показателей:
  - сон;
  - активность;
  - настроение;
  - экранное время.
- Детальные экраны рекомендаций с возможностью отметить выполнение.
- Дневник состояния и экран сохранения записи.
- История записей и интерфейс формирования отчёта.
- Уведомления, настройки и экран отчёта.

## Сценарии использования

Этот прототип подойдёт для:

- презентации концепции мобильного приложения;
- согласования состава экранов и пользовательского пути;
- обсуждения UX-потока онбординга и аналитики;
- подготовки к дальнейшей реализации на React;
- демонстрации интерфейса заказчику, команде или дизайнеру.

## Ограничения прототипа

- Нет интеграции с backend.
- Нет реальной авторизации.
- Нет сохранения пользовательских данных.
- Нет экспорта PDF, только интерфейсная заглушка.
- Метрики, графики и рекомендации статичны.
- Разрешения и согласия показаны как UI-сценарий, без системной интеграции.

## Возможные следующие шаги

- Вынести все экраны из одного файла в отдельные компоненты.
- Заменить числовую навигацию `setScreen(...)` на именованные маршруты.
- Подключить управление состоянием форм.
- Добавить реальные данные аналитики и историю записей.
- Реализовать адаптацию под production-сборку без CDN.
- Подключить API, хранение данных и экспорт отчётов.

## Итог

MindMonitor — это аккуратный интерактивный прототип мобильного приложения для отслеживания психоэмоционального состояния. Он уже подходит для демонстрации структуры продукта, пользовательских потоков и ключевых разделов интерфейса, а также может служить основой для дальнейшей полноценной разработки.
