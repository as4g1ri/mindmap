MindMonitor — это прототип интерфейса React для мобильного приложения, предназначенного для мониторинга психоэмоционального состояния пользователя. Приложение демонстрирует основные экраны и взаимодействия, включая регистрацию, авторизацию, согласие на обработку данных, настройки и аналитику состояния.

Основные возможности:

Приветственный экран — начальное приветствие и краткое описание функционала.
Регистрация и вход — формы для создания аккаунта и авторизации пользователя.
Согласие и разрешения — сбор согласия на обработку персональных данных и предоставление доступа к устройству (шаги, сон, уведомления, экранное время).
Главный экран — обзор текущего состояния, динамика за неделю и быстрый доступ к аналитике, дневнику и рекомендациям.
Аналитика и детали — визуализация показателей (сон, активность, настроение, экранное время) с графиками и подробной информацией.
Рекомендации — список персонализированных рекомендаций с детализацией и возможностью отметить выполнение.
Дневник и история — возможность вести записи о состоянии и просматривать историю.
Уведомления и настройки — управление уведомлениями, источниками данных и другими параметрами приложения.
Отчёты — генерация сводных данных по периодам с возможностью экспорта (интерфейс).
